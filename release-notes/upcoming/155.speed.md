`np.round(x, decimals)`, `np.around` and `x.round(decimals)` on a `float64` array of up to 4,096 elements, with `decimals` a Python int from 0 to 15, skip NumPy's call path and give NumPy's result bit for bit: `np.round(x, 2)` is about 7.5x faster than NumPy at 16 elements and 2.2x at 4,096, measured on x86-64. Longer arrays, and calls where NumPy would warn, go to NumPy as before.
