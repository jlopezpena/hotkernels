hotkernels now runs on Linux x86-64, with a second set of kernels written for AVX2: `install()` works on any processor with the x86-64-v3 instruction sets (Intel since 2013, AMD since 2015), and wheels are published for glibc Linux. On an Intel Core i5-14600KF at a million elements, `np.sum` on `uint8` is about 42x faster than NumPy, `x[mask]` on `float32` about 16x, `np.cumsum` on `float32` about 13x and `np.argmax` about 1.8x; `np.clip` and `x.astype(np.float32)` are level with NumPy there, which already has vector loops for them.
